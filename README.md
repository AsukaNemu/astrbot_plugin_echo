# astrbot_plugin_echo

AstrBot 插件 — 在群聊中收到 `/echo` 时，将内容私发给发送者。

## 用法

在群聊中发送：

```
/echo 今天吃了吗？
```

Bot 会将 `今天吃了吗？` 私发给发送者，不会在群内回复。

## 安装

将本仓库克隆或下载到 AstrBot 的插件目录：

```
AstrBot/data/plugins/astrbot_plugin_echo/
```

然后在 AstrBot WebUI 中启用插件。
